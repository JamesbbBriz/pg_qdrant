# Lexical dependency license texts

These files preserve the license texts from the published Cargo packages
`tantivy 0.26.2`, `tantivy-fst 0.5.0` and `levenshtein_automata 0.2.1`.
The Tantivy AUTHORS file accompanies its copyright notice. Their MIT licenses
remain upstream licenses; the project's AGPL-3.0-only statement applies to
original project material.

The complete locked package coordinates, registry checksums and declared
license expressions are recorded in [the dependency inventory](../../docs/dependency-graph.json).
This directory covers these direct lexical dependencies only. Complete
transitive notices, bundled native materials and distribution review remain
required by P5-LICENSE before a release.
